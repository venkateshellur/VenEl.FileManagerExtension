🗂️ Browser-Style Multi-Tab Browsing
Work with multiple project folders or drives side-by-side without opening extra editor windows. Each tab preserves its own independent path, history stack, and search query.
🖱️ Middle-Click Power Shortcuts
• On Folders: Scroll-wheel click on any folder card or row to open it immediately in a New Tab without losing your place.
• On Tabs: Scroll-wheel click directly on any tab in the top strip to close it.
📑 Tab Context Menu
Right-click any tab in the top strip for power actions: Duplicate Tab, Open in Terminal, Reveal in Finder/Explorer, Copy Folder Path, Close Other Tabs, or Close Tabs to Right.
💾 Persistent Tab Sessions
Your open tabs and active selection are saved to local session storage. Reopening the File Manager or restarting VS Code automatically restores your exact open tabs!
🌿 Real-Time Git Status Badges
Files in your Git repositories display visual indicators in real-time:
• U Untracked: Brand new file not yet added to Git.
• M Modified: Uncommitted working tree modifications.
• A Added / Staged: Changes staged in the Git index.
• D Deleted: File removed from the working tree.
⚖️ Live Side-by-Side Diff with HEAD
Right-click any modified or staged file and click Compare with HEAD (Diff) to open VS Code's native visual diff editor side-by-side.
 Branch & Commit Sync Status
The bottom status bar shows your active branch name and sync status (e.g. main ↑1 ↓0). Click on it anytime to refresh Git status on demand.
⚡ Instant Live Filter (/)
Press / anywhere to focus the search bar. As you type, the file view filters in real-time with zero lag. Press Esc to clear the filter.
🤖 Machine Agent Search (Spotlight & PowerShell)
Click the scope button (📁 Folder → ⚡ Machine) in the toolbar. This unleashes deep operating system indexing (macOS Spotlight / Windows PowerShell) to query your entire hard drive in milliseconds! Click any result's directory chip to jump straight there.
🍞 Interactive Breadcrumbs & Direct Path Input
Click any folder crumb in the address bar to jump up to that folder. Click on the address bar background to type or paste any absolute path, or click ▾ to quickly switch between Root drives and User Home.
⭐ Bookmarks & Pinned Favorites
Click ☆ Pin Folder in the Bookmarks bar or right-click any folder to pin it. Pinned folders appear as 1-click quick-access chips across all sessions.
👁️ Spacebar Quick Look & Rich Interactive Previews
Select any file and press Spacebar for an instant full-screen Quick Look preview, or glance at the right-hand preview pane. Supports:
• 📊 Spreadsheets (CSV, TSV): Fast native table parser with sticky headers, row numbers, and column counts.
• 📗 Excel Workbooks (.xlsx, .xls): Multi-sheet navigation with interactive sheet tabs and cell grid views.
• 📘 Word Documents (.docx): Formatted document reader view with styled headings and tables.
• 📕 PDF Documents (.pdf): Native inline PDF reader with page navigation.
• 🎵 Audio & Video (.mp3, .wav, .mp4, .webm): Built-in HTML5 media players.
• 📝 Markdown (.md): 1-click toggle between Rendered HTML view and Raw Source.
• 💻 Source Code: Syntax preview with line counts, file size, and 1-click clipboard copy.
⊞ 5 View Layout Modes
Use the Layout menu to toggle between Details (sortable multi-column table), List (clean compact rows), Grid (standard card tiles), Large Icons (high-res previews), and Compact.
💻 Integrated Terminal & Native OS Reveal
Click Terminal in the toolbar or context menu to spawn a VS Code terminal pre-navigated to that folder. Click Reveal in Finder / Explorer to open your operating system's native file window.
🏷️ Smart Batch Renamer
Select multiple files with Ctrl/Cmd + click or Shift + click (or press Ctrl/Cmd + A for Select All). Press Ctrl/Cmd + Shift + R or click Batch Rename. Features 5 tabs: Find & Replace (with Regex), Add Prefix/Suffix, Sequential Numbering (e.g. 001, 002...), Case Transformation (lowercase, UPPERCASE, Title Case, camelCase, kebab-case, snake_case), and Extension Normalization with live real-time collision preview.
🗜️ Zip Compression & One-Click Extraction
Compress any selected file(s) or folder(s) directly into a .zip archive using the toolbar button or right-click menu. For archive files (.zip, .tar.gz, .tgz), right-click to Extract Here or Extract to Subfolder/ instantly.
⚙️ Engine Diagnostics & Direct-to-Editor Mode
Click ⚙️ in the header to view engine diagnostics, endpoint status, and quick VS Code configuration controls.
